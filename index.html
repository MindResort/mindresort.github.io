101 房间说明

How the table plays
AI · 记牌

对手会算牌

AI 记住每一张打出去的牌，按剩余张数估算你能不能接住。你只剩一两张时，它会拼命顶。

AI · 配合

队友会让牌

对家一般不压你的牌，只在估计你的牌会被对手接走、或者它能一手出完时才压。你快出完时，它还会故意出小牌喂给你。

进贡 · 概率

进贡也有算计

还贡时会算这张牌送过去，会不会让对面凑出炸弹或同花顺。

理牌 · 推荐

帮你出主意

一键理出同花顺和炸弹，AI 推荐会写出每种出法后续还要几手、被管的概率。

102 房间说明

Railway Atlas · 0.6.0 (1)
  1. 01

    打开网页版

    Windows、Android、iPhone 和电脑浏览器都能用：wongary.github.io/railway-atlas。iPhone 上可以从 Safari 添加到主屏幕，其他平台可以装成网页应用（PWA）。

  2. 02

    Mac 下载应用

    在 0.6.0 发布页下载 macOS 压缩包，解压后打开。这个包只支持 Apple 芯片（arm64）的 Mac。

  3. 03

    地图问答

    想对着地图提问，需要填自己的服务商地址、模型 ID 和 API Key。网页不提供额度；浏览器能不能直连，取决于服务商的 CORS 设置、模型权限和账号余额。

API Key 只存在当前页面的内存中，不写进仓库，也不随网页保存。

macOS 包是 arm64 临时签名（ad-hoc），没有经过公证，首次打开可能要在系统设置里允许。

铁路线、车站和城市轨道数据来自 OpenStreetMap 社区（ODbL 1.0）。G337 的沿线资料是随包快照，时刻是一次性样例，不是实时列车位置。
